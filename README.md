# habit-tracker

Трекер привычек. Можно добавлять свои привычки (например, пить воду, читать, зарядка) и каждый день отмечать, выполнил или нет. Потом смотреть статистику.

Статус проекта: продумываю MVP

Файлы:
- README.md - описание
- project-notes.md - заметки
- api-plan.md - план api

Что планирую использовать: Python (FastAPI), PostgreSQL, Docker
